Fundamentals of Software Engineering – Git Branching Exercise

This project was developed as part of the Fundamentals of Software Engineering course.

It is a practical exercise focused on working with Git version control, specifically on understanding and using Git branching workflows.

The main goal of the assignment was to learn and practice collaborative development techniques using Git, including:

creating and managing branches
working with feature branches
performing merges between branches
resolving merge conflicts
performing code reviews (pull/merge request workflow)
understanding basic review processes in team development

The exercise demonstrates how modern software teams use Git for parallel development, collaboration, and safe integration of changes into a shared codebase.
